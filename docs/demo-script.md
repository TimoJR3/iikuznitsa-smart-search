# Сценарий демо-видео (до 3:00, один дубль)

Записываем стенд https://smart-search.containerapps.ru в браузере, окно 1440×900 или весь экран. Один непрерывный фрагмент, без монтажа. Голос — по тексту ниже (можно своими словами). Подписи и стрелки — по желанию.

## Подготовка (до записи, 5 минут)

1. Открыть стенд и один раз выполнить «программа для чертежей», чтобы ответ GigaChat попал в кеш. На записи он придёт сразу.
2. Обновить страницу (F5), очистить строку поиска, закрыть лишние вкладки и уведомления.
3. Проверить звук микрофона и что в кадре нет ключей и личных данных.
4. Отрепетировать один раз с секундомером. Если не укладываетесь — уберите шаг 6.

## Чего не показывать

Функции, которых нет в продукте: реальные корзины «часто покупают вместе», цены конкурентов, интеграцию с витриной. Они перечислены в описании как нереализованные.
