# Атлас каталога — умный поиск для store.softline.ru · «Умный поиск на сайте», трек «Аналитик данных»

**Стенд:** https://smart-search.containerapps.ru · **Код:** https://github.com/TimoJR3/iikuznitsa-smart-search

## Подход и архитектура

Покупатель вводит запрос как привык: с жаргоном, опечаткой, в другой раскладке или описанием задачи. Поиск нормализует запрос (раскладка, транслитерация, опечатки, словарь жаргона), определяет намерение «оборудование или ПО» и ищет гибридно: слова (BM25) плюс смысл (эмбеддинги), ранги объединяются RRF. Неуверенные запросы уточняет GigaChat вторым шагом, пока выдача уже на экране. В ответе всегда не меньше 4 товаров, рядом — допродажа: совместимость, подтверждённая вендорами, экосистема вендора, сопутствующие разделы, аналоги, акции и «дешевле аналогов». Каждый поиск пишется в журнал; команда магазина видит карту спроса, запросы без ответа и пополняет словарь одной кнопкой. Данные каталога обрабатываются на стенде, наружу уходит только текст неуверенного запроса в GigaChat.

## Стек и модели

Python 3.11, FastAPI, SQLite, vanilla JS + Canvas. Эмбеддинги intfloat/multilingual-e5-small (MIT), локально на CPU. Уточнение запросов — GigaChat-2 через GigaChat API (облако Сбера). PyTorch, sentence-transformers, SciPy, scikit-learn (t-SNE для карты), RapidFuzz, pandas. Стенд: Cloud.ru Evolution Container Apps, 1 vCPU, 2 ГБ, Docker-образ из Artifact Registry.

## Принцип работы и запуск

YML-фид (136 040 SKU) → 10 200 карточек продуктов в наличии → индекс BM25 + эмбеддинги + 2D-карта. Запрос → понимание → гибридный отбор → допродажа → журнал → аналитика. Запуск: положить фид и выборку в `data/raw`, `python scripts/build_index.py`, `uvicorn app.main:app`; стенд — `deploy/cloudru/Dockerfile`. API для витрины: `/api/search`, `/api/suggest`.

## Реализованная и нереализованная функциональность

**Реализовано за спринт.** Понимание жаргона, опечаток, раскладки и транслитерации; намерение «сервер — оборудование / ПО для сервера»; гибридный поиск с пояснением «почему здесь»; GigaChat для описаний задачи; подсказки товаров при вводе; фильтры и сортировка; замена продукта, которого нет в каталоге (TeamViewer, Zoom, Veeam, Windows Server и др.); метки реестра российского ПО и сертификатов ФСТЭК из фида; рекомендации со ссылками на документацию вендоров и Ready for Astra; карта спроса, пополнение словаря, калькулятор эффекта. Замеры: на выборке организатора верный первый товар в 10 из 10 запросов, на наборе из 26 запросов — 96% (поиск по точному совпадению — 35%), пустая выдача 0% против 46%. Ответ без LLM: 0,15 с локально, ~0,24 с на стенде; уточнение GigaChat ~2 с. 20 автотестов.

**Нереализовано.** «Часто покупают вместе» по реальным корзинам: в данных нет заказов, используются правила совместимости и источники вендоров. Сравнение с ценами конкурентов: нет источника цен, показываем акции и цену относительно аналогов в каталоге. Ранжирование по марже и популярности: этих полей нет в фиде. Журнал на стенде хранится во временной папке и обнуляется при перезапуске. Проверка на реальном потоке запросов и A/B-тест — после внедрения.

## Стоимость эксплуатации и внедрения

**Эксплуатация.** При 15 000 поисков в месяц (~500 в день): сервер Container Apps 8,40 ₽/ч ≈ 6 132 ₽/мес (F), модели ≈ 0,0012 ₽ на запрос (V: e5 локально, GigaChat-2 при 10% запросов, 225 токенов, 53,28 ₽ за 1 млн без НДС). Итог F + N × V ≈ 6 150 ₽/мес, ≈ 0,41 ₽ на поиск. Цены без НДС на 27.11.2026, расчёт — [docs/cost-calculator.xlsx](cost-calculator.xlsx).

**Внедрение.** 40–60 ч разработчика на подключение API к витрине, регулярную пересборку индекса из фида и настройку словаря; инфраструктура — тот же тариф. Ожидаемый эффект по цифрам ТЗ (15 000 поисков, 40% → 7% неудачных, 40% уходят, конверсия 7,5%, чек 50 000 ₽ — допущение): около +149 заказов и 7,4 млн ₽ в месяц; подтверждается A/B-тестом.
